
# TrimTime AI ✂️

AI-Powered Barber Appointment & Service Duration Prediction System.

## About
TrimTime AI is a Machine Learning based platform that predicts the time required for barber services such as haircuts, beard trimming and facials.

## Objectives
- Predict service duration using Machine Learning.
- Manage customer appointments.
- Estimate customer waiting time.
- Help barbers manage their schedules.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- MySQL
- Streamlit

## Machine Learning
Regression algorithms will be trained and evaluated to predict service duration.
